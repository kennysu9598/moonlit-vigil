# Current status · v0.6.0

Standalone Godot 2D 3v3 battle with shared energy, statuses, healing/shields, boss charge/interrupt/enrage, victory/defeat and replay. Auto battle and 1×/2×/3× speed exist. v0.6.0 completes audiovisual depth on every axis: a new `skill_vfx.gd` library gives all six units（绯羽红刀 / 澄铃青白 / 玄刃蓝剑 / 灾鸦黑焰 / 灯魇灯火 / 荒祟紫黑）× 3 skills individually designed effects — T1 0.60 s, T2 0.86 s, T3 ultimate 2.80 s staging with cast circle, full-screen flash, vignette and hit-stop; enemy skills carry ground warning circles. Shields are visualized on two channels: caster-colored health-bar shield pips plus a per-character glow outline shader (auto-hidden at zero, burst particles on break). Boss charges are telegraphed three ways: ground circle + vignette focus + HUD bar marked「可被打断」. Action layering adds tiered anticipation for normal/skill/ultimate (0.06/0.09/0.14 s), directional knockback, dash afterimages and persistent death poses. Audio v2: 绯羽 corrected to a male voice (YunxiNeural), 荒祟 pitch fixed 0.62→0.78 for intelligibility, five male and one female voices stay distinct; all 12 combat SFX replaced with weighty RPG-grade sounds chosen by low-frequency A/B testing; the battle track is remade at 112 BPM with taiko/erhu/guzheng (ACE-Step pipeline, -16 LUFS) and a new `title_theme` is wired into the title screen. The v0.5.0 audio stack (`AudioMgr` buses, 8-slot SFX pool, 0.8 s crossfade) and game-feel layer remain in place.

Enabled principal creature VFX: phoenix ultimate and dragon ultimate. Their artwork and local-motion frames were independently inspected. Other older principal VFX and geometric ground cracks are disabled for visual quality; the game's skill logic remains available. Environment color/clouds and impact response remain enabled. The eighteen v0.6.0 skill effects were accepted through a 75 s captured gameplay recording with nine extracted frames independently reviewed.

Known limitations: few character poses; four-key-pose phoenix; single-sided painted dragon mesh; only one encounter; Chinese UI; Windows-only packaged validation; the top charge bar occasionally overlaps the result/interrupt banner（P2，下版修复）; screen recordings carry no audio track（gdigrab 限制，音频验收走测试断言 + 音频 manifest，真人听审仍待）. The included headless tests prove mechanics, not aesthetics.

Automated headless tests (also run in CI via GitHub Actions): `tests/test_combat.gd`, `tests/test_auto.gd`, `tests/test_audio.gd`, `tests/test_voice.gd`, `tests/test_art_fx.gd`, `tests/test_vfx.gd`（v0.6.0 新增：18 招构造 + 护盾 + 预警断言）；`tests/art_gallery.gd` 为画作画廊工具。

This public checkout omits rejected 3D GLBs, old Unity/Godot 3D experiments, internal handoffs, personal paths and editor caches. They are not required to run the 2D game.
