# 20260917T0xxx voice-wiring（36 条配音接入游戏触发点）

- 身份：glm-general（施工席 worker，GLM-5.3-Flash）
- 时间：2026-09-17
- 派工卡：main.gd + audio_manager.gd 配音接线（36 voice assets → 触发点）

## 做了什么

1. 归档改前版本：`archives/20260917-voice-wiring/{main.gd,audio_manager.gd}`。
2. `scripts/audio_manager.gd`：
   - 新增 `const VOICE_UNITS := ["feiyu","zaiya","chengling","dengyan","xuanren","huangshuo"]`（顺序=combat id 0-5）与 `VOICE_DB=-2.0`。
   - 新增单实例语音通道 `_voice`（AudioStreamPlayer，bus=SFX，volume_db=-2）；mute 经 SFX 总线自动跟随。
   - 新增 `play_voice(name_value)`（`res://assets/audio/voice/{name}.ogg`，ResourceLoader.exists 兜底，stop+覆盖=单实例互顶）与 `play_unit_voice(unit_idx, action)`（非法索引直接 return）。
3. `scripts/main.gd` 五处接线：
   - `_start_battle`（约 L296）：feiyu(0) entrance 即播；0.9s 后 huangshuo(5) entrance（timer 内校验 phase=="battle"，防重开误播）。
   - `_cast`（约 L381）：perform 成功后施法者 cast 语音，紧接原 cast_* 音效（语音主、音效辅，原音效逻辑未动）。
   - `_show_events` damage 分支（约 L429）：目标 hurt() 后播 hurt 语音（单通道自动顶掉，天然防连喊）。
   - `_show_events` 新增 "death" 分支（约 L434）：combat.gd L195 本就发出 death 事件（此前无消费），现播 death 语音。
   - `_finish`（约 L500）：winner 方存活者随机 1 人播 victory（胜）/defeat（败）；0.3s 后原 win/lose play_music 进（crossfade 保持）。
4. 新增 `tests/test_voice.gd`（SceneTree 模式，同 test_audio.gd 风格）：VOICE_UNITS 长度=6 且顺序正确、36 文件 exists 逐一断言、非法索引/缺失文件不炸不赋值、play_unit_voice 映射正确（chengling_cast）、单实例覆盖语义、bus=SFX、volume=-2dB。
